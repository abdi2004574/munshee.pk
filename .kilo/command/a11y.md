Audit the codebase for accessibility issues.

## Checks
1. **Keyboard navigation**: Every interactive element must be reachable via Tab
2. **Focus states**: No `focus:outline-none` without a visible replacement
3. **ARIA labels**: All icon-only buttons must have `aria-label`
4. **Form labels**: Every `<input>`, `<select>`, `<textarea>` must have a matching `<label>`
5. **Contrast**: Body text must meet 4.5:1, large text 3:1
6. **Landmarks**: Page must have `<main>`, `<nav>`, `<footer>` where appropriate
7. **Skip link**: A skip-to-content link should be present
8. **Color-only cues**: No information conveyed by color alone (add text/icon)
9. **Dynamic content**: Toasts and dialogs must announce themselves (role="status", aria-live)

## Process
1. Grep for `aria-`, `role=`, `<label`, `focus:outline-none` across `src/`
2. Check for missing labels on form fields
3. Verify contrast ratios for text/background color pairs
4. Report each violation with file, line, WCAG criterion, and fix

## Output
A structured accessibility audit report with pass/fail for each check.
